# ADR 0055: Resources editorial directory

## Status

Accepted

## Context

The Resources page reused the homepage's Ways to Work Together showcase. That
presentation made the four destinations visually equivalent and did not make
their different formats immediately clear. The page also relied on one
background photograph instead of giving each resource a recognizable visual.

## Decision

Give the Resources route its own editorial directory. Use a compact split hero
followed by alternating image-and-copy rows. Each resource receives a verified
format label, a specific action, and an existing approved image when one is
available. The Pattern Interrupt uses a route-owned typographic visual rather
than unrelated stock photography.

Keep this composition route-owned. Do not change the shared
`WorkTogetherShowcase`, which remains appropriate for the homepage.

## Consequences

- Visitors can distinguish a tool, audio series, newsletter, and coaching
  experience before following a link.
- Existing resource destinations remain unchanged.
- Resource imagery can be replaced independently without changing shared site
  components.
- The page carries more visual content and therefore requires responsive image
  and mobile-layout review.
