# ADR 0030: Align the About page with the editorial site system

## Status

Accepted

## Decision

Treat `/about` as a main-site page with the same immersive editorial hero and
typographic hierarchy used by the homepage and Services page. Place the shared
navigation transparently over the hero, keep the approved About photography and
copy, and let the opening section layer over a pinned hero during the initial
scroll transition.

Use the shared Bodoni display scale for hero and section headlines, EB Garamond
for supporting copy, and Montserrat Medium for small uppercase chapter labels.
Preserve intentional display moments such as the italic realization statement,
while normalizing the core headline, subheader, and body-copy rhythm. Present
the realization statement on black for a restrained high-contrast transition.
Reduce that realization statement's display scale by 40% across desktop and
mobile.
Set both text treatments in the closing portrait callout 10% below their prior
display scale on desktop and mobile.

## Consequences

- The About page visually belongs to the same site system as Home and Services.
- Existing About copy and photography remain unchanged.
- The About hero receives the shared transparent navigation treatment.
- Desktop and mobile typography use the same responsive hierarchy as the other
  main site pages.
