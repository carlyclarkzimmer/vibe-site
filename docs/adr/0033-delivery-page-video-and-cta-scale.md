# ADR 0033: Rebalance the Laser Coach delivery hero

## Status

Accepted

## Decision

On the 5-Minute Laser Coach delivery route, reduce the visible "Video
Walkthrough" heading to half its prior responsive type scale and remove the
secondary "Helpful if you're new to Chat GPT" wording.

Increase the delivery page's installation calls to action by 50%, including
their type size and internal spacing, so the installation action is the
strongest visual element around the walkthrough.

Remove the black feature-list section so the walkthrough leads directly into
the Carly introduction.

Keep installation calls to action beneath the walkthrough and in the Carly
introduction.

## Consequences

- The walkthrough video and installation action take priority over the heading.
- Both installation calls to action remain visually consistent with each other.
- Mobile buttons continue to use the full available width.
- The delivery flow is shorter and no longer repeats the tool's benefits.
